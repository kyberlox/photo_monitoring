# Виртуальная карта – Photo Monitoring

Проект для мониторинга фотографий по географическим локациям. Позволяет пользователям добавлять точки на карту, прикреплять к ним фотографии с комментариями и просматривать наблюдения.

## Архитектура

- **Бэкенд**: FastAPI + SQLAlchemy (асинхронный) + PostgreSQL
- **Фронтенд**: (планируется) React/TypeScript с картами
- **Инфраструктура**: Docker Compose, Nginx

## Функциональность

### Сущности

1. **Локация (Location)**
   - Координаты (X, Y)
   - Название (опционально)
   - Список прикреплённых изображений

2. **Изображение (Image)**
   - Название
   - Комментарий
   - Файл изображения (хранится на диске, путь в БД)
   - Автор (пользователь)
   - Дата создания

3. **Пользователь (User)**
   - Полное имя
   - Флаг администратора

### API Endpoints

- `GET /locations/` – список всех локаций с изображениями
- `POST /locations/` – создать новую локацию
- `PUT /locations/{id}` – обновить локацию
- `DELETE /locations/{id}` – удалить локацию и все её изображения (только для администраторов)

- `GET /images/` – список изображений (с фильтрами по локации и автору)
- `POST /images/` – загрузить новое изображение (base64)
- `PUT /images/{id}` – обновить метаданные или заменить изображение
- `DELETE /images/{id}` – удалить изображение (только автор)

- `GET /users/` – список пользователей
- `POST /users/` – создать пользователя
- `PUT /users/{id}` – обновить пользователя
- `DELETE /users/{id}` – удалить пользователя

## Установка и запуск

### Требования

- Docker и Docker Compose
- Python 3.13 (для локальной разработки)

### Быстрый старт

1. Клонируйте репозиторий:
   ```bash
   git clone <repository-url>
   cd photo_monitoring
   ```

2. Создайте файл `.env` на основе `.env.example`:
   ```bash
   cp .env.example .env
   # Отредактируйте .env при необходимости
   ```

3. Запустите сервисы через Docker Compose:
   ```bash
   docker-compose up -d
   ```

4. Инициализируйте базу данных:
   ```bash
   docker-compose exec fastapi python app/database/init_db.py
   ```

5. Откройте в браузере:
   - API документация: http://localhost:8000/docs
   - Основное приложение: http://localhost

### Локальная разработка (без Docker)

1. Установите зависимости:
   ```bash
   cd app
   pip install -r requirements.txt
   ```

2. Запустите PostgreSQL (например, через Docker):
   ```bash
   docker run --name postgres_async -e POSTGRES_USER=kyberlox -e POSTGRES_PASSWORD=gbljhfcbyf -e POSTGRES_DB=pdb -p 5432:5432 -d postgres:15-alpine
   ```

3. Инициализируйте БД:
   ```bash
   python app/database/init_db.py
   ```

4. Запустите сервер FastAPI:
   ```bash
   fastapi run app/main.py --port 8000
   ```

## Особенности реализации

### Хранение файлов

- Изображения сохраняются на диск в папку `uploads/images/`
- В базе данных хранится только путь к файлу
- При загрузке клиент отправляет изображение в формате base64
- При запросе изображения сервер конвертирует файл обратно в base64

**Важно**: Папка `uploads/` добавлена в `.gitignore` и не должна попадать в систему контроля версий.

### Асинхронность

- Все операции с базой данных используют асинхронные драйверы (asyncpg)
- FastAPI работает в асинхронном режиме для высокой производительности

### Безопасность

- В роутах заложены проверки прав доступа (авторство, административные права)
- CORS настроен для работы с фронтендом
- JWT-аутентификация может быть легко добавлена
