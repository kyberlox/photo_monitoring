# Виртуальная карта – Photo Monitoring

Проект для мониторинга фотографий по географическим локациям. Позволяет добавлять точки на карту, прикреплять к ним фотографии с комментариями и просматривать наблюдения.

## Архитектура

- **Бэкенд**: FastAPI + SQLAlchemy (асинхронный) + PostgreSQL
- **Фронтенд**: (планируется) React/TypeScript с картами
- **Инфраструктура**: Docker Compose, Nginx

## Функциональность

### Сущности

1. **Локация (Location)**
   - Координаты (массив [X, Y])
   - Название (опционально)
   - Список прикреплённых фотографий

2. **Фото (Photo)**
   - Название
   - Комментарий (опционально)
   - Файл изображения (хранится на диске, путь в БД)
   - URL для доступа к файлу (`/static/photos/...`)
   - Дата создания
   - Связь с локацией

### API Endpoints

#### Локации
- `GET /locations/all` – список всех локаций
- `GET /locations/id={id}` – получить локацию по ID
- `POST /locations/add` – создать новую локацию (можно сразу загрузить фото)
- `PUT /locations/id={id}` – обновить локацию
- `DELETE /locations/id={id}` – удалить локацию и все её фото

#### Фото
- `GET /photos/all` – список всех фото (можно фильтровать по `location_id`)
- `GET /photos/id={id}` – получить фото по ID (с base64)
- `POST /photos/add` – загрузить новое фото (base64)
- `PUT /photos/id={id}` – обновить метаданные или заменить изображение
- `DELETE /photos/id={id}` – удалить фото

## Установка и запуск

### Требования

- Docker и Docker Compose
- Python 3.13 (для локальной разработки)

### Быстрый старт

1. Клонируйте репозиторий:
   ```bash
   git clone <repository-url>
   cd photo_monitoring
   ```

2. Создайте файл `.env` на основе `.env.example`:
   ```bash
   cp .env.example .env
   # Отредактируйте .env при необходимости
   ```

3. Запустите сервисы через Docker Compose:
   ```bash
   docker-compose up -d
   ```

4. Таблицы базы данных создаются автоматически при запуске приложения.

5. Откройте в браузере:
   - API документация: http://localhost:8000/docs
   - Основное приложение (через Nginx): http://localhost

### Локальная разработка (без Docker)

1. Установите зависимости:
   ```bash
   cd app
   pip install -r requirements.txt
   ```

2. Запустите PostgreSQL (например, через Docker):
   ```bash
   docker run --name postgres_async -e POSTGRES_USER=kyberlox -e POSTGRES_PASSWORD=gbljhfcbyf -e POSTGRES_DB=pdb -p 5432:5432 -d postgres:15-alpine
   ```

3. Запустите сервер FastAPI:
   ```bash
   fastapi run app/main.py --port 8000
   ```

## Особенности реализации

### Хранение файлов

- Фотографии сохраняются на диск в папку `uploads/photos/`
- В базе данных хранится только путь к файлу
- При загрузке клиент отправляет изображение в формате base64
- При запросе фото сервер конвертирует файл обратно в base64

**Важно**: Папка `uploads/` добавлена в `.gitignore` и не должна попадать в систему контроля версий.

### Асинхронность

- Все операции с базой данных используют асинхронные драйверы (asyncpg)
- FastAPI работает в асинхронном режиме для высокой производительности

### Автоматические миграции

- Таблицы создаются автоматически при запуске приложения через событие `startup` (см. `app/main.py`)
- Не требуется ручной запуск скриптов инициализации

### Безопасность

- CORS настроен для работы с фронтендом (разрешены все домены в разработке)
- В продакшене необходимо настроить ограничения
